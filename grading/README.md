# 채점 기준 파일 만들기

자동 채점은 수행평가마다 **채점 기준 파일(.py) 하나**가 필요합니다.
채점기는 학생 코드를 다시 실행한 뒤, 코드 글자가 아니라 **실행 결과**(그래프의 크기·제목·색, 변수 값, 출력 등)를 검사합니다.
그래서 `color='olive'`와 `color='#808000'`처럼 쓰는 방식이 달라도 결과가 같으면 같은 점수를 받습니다.

> **채점 기준 파일은 GitHub에 올리지 마세요.** 정답 정보가 들어 있습니다.
> 교사용 도구 **채점** 탭에서 올리면 선생님 드라이브에 비공개로 저장되고, 다음부터 자동으로 불러옵니다.

## 가장 쉬운 방법: AI에게 만들어 달라고 하기

학생에게 줄 **문제 파일**과 선생님이 푼 **완성본**(.ipynb)을 Claude 같은 AI에게 주고 이렇게 요청하세요.

> 이 저장소의 `notebook/grader_core.py`와 `grading/example_rubric.py` 형식에 맞춰,
> 첨부한 문제 파일과 완성본으로 채점 기준 파일을 만들어 줘.
> 문제에 적힌 항목별 배점을 그대로 쓰고, 판단이 애매한 항목은 OPTIONS로 빼서 알려 줘.

만든 뒤에는 꼭 **완성본을 채점해서 만점이 나오는지**, 일부러 틀린 답에서 맞게 감점되는지 확인하세요. (아래 "시험해 보기")

## 파일 구조

```python
def check_q1(ctx):
    ax = ctx.ax                     # 학생 코드가 그린 그래프 (없으면 None)
    ok = ctx.ran_ok and ax is not None
    return [
        R("1. 그래프 크기 25x10", ok and figsize_is(ctx, 25, 10)),
        R("2. 제목", ok and ax.get_title().strip() == "Protein by Menu"),
        R("3. 실행하여 출력", ctx.output_ok, ctx.output_note()),
    ]

RUBRIC = {
    "title": "수행평가 이름",
    "base": 10,                         # 기본 점수
    "setup_heading": "## 1.데이터",      # 이 제목 아래 코드는 '선생님 문제 파일'의 코드로 실행 (학생이 고쳐도 무시)
    "problems": [
        # heading: 문제 파일의 마크다운 제목. 그 아래 코드 셀들을 학생 답으로 본다
        {"id": "q1", "heading": "## 2.막대 그래프", "title": "막대 그래프", "check": check_q1},
    ],
}
```

- `R(항목 이름, 맞았는지, 감점 이유="", points=1)` — 항목 하나
- 문제 칸은 **문제 파일의 마크다운 제목**(`## ...`)으로 찾습니다. 학생이 셀을 더 만들어도 그 제목 아래 코드 셀은 모두 합쳐서 채점합니다.

### ctx 에 들어 있는 것

| 이름 | 내용 |
|---|---|
| `ctx.fig`, `ctx.ax` | 학생 코드가 만든 그래프 중 내용이 가장 많은 것, 그 첫 번째 축 |
| `ctx.ran_ok` | 그래프가 하나라도 그려졌는지 (오류가 나도 그 전까지 그린 것은 채점) |
| `ctx.error` | 실행 중 오류 메시지 (없으면 None) |
| `ctx.output_ok`, `ctx.output_note()` | "실행하여 출력" 항목용: 오류 없이 실행됐고 제출 파일에 그래프가 있는지 |
| `ctx.ns` | 학생 코드 실행 후의 변수들 (예: `ctx.ns.get("total")`) |
| `ctx.code` | 그 문제 칸의 학생 코드 (글자로 확인해야 할 때만, 예: `for` 사용 여부) |
| `ctx.cells` | 그 문제 칸의 셀들 (제출 파일에 남은 출력 확인용) |

### 도우미 함수 (grader_core.py)

| 함수 | 용도 |
|---|---|
| `figsize_is(ctx, 가로, 세로)` | 그래프 크기 |
| `same_color(실제, '색이름')` | 색 비교 (`'olive'` = `'#808000'` 모두 인정) |
| `xtick_texts(ax)` | x축 눈금 글자 목록 |
| `xtick_rotation_is(ax, 각도)` | x축 눈금 회전 |
| `grid_state(ax, 'x' 또는 'y')` | (그리드가 보이는지, 투명도) |
| `line_xy(line)` | 꺾은선의 (x값, y값) |
| `numbers_equal(a, b)` | 숫자 목록이 같은지 |
| `close(a, b)` | 숫자가 같은지 (소수점 오차 허용) |

예시는 [example_rubric.py](example_rubric.py)와 짝이 되는 문제 [docs/예시_문제.ipynb](../docs/예시_문제.ipynb)를 보세요.

## 시험해 보기

1. 교사용 도구 **과제 배포**로 시험용 반에 문제 파일을 냅니다 (초안이어도 됨).
2. 시험용 학생 계정으로 **완성본 코드**를 붙여 실행한 뒤 제출합니다.
3. **채점** 탭에서 채점 기준 파일을 올리고 채점 → 만점이 나오는지 확인합니다.
4. 일부러 몇 군데 틀리게 낸 제출물로 감점 항목이 맞는지 확인합니다.

## 알아둘 점

- 학생 코드가 30초 안에 끝나지 않으면(무한 반복 등) "채점 시간 초과"로 표시됩니다.
- 채점 엔진을 건드리는 코드(`import js`, `sys.modules`, `globals()` 등)가 있으면 "의심 코드"로 표시하고 다른 학생 채점에 영향이 없도록 따로 채점합니다. 이 학생은 직접 확인하세요.
- 어떤 표시도 자동으로 감점하지 않습니다. 최종 점수는 선생님이 확인하고 정합니다.
