# 우리 학교에 설치하기

AI 기능 없는 코랩형 파이썬 노트북을 **우리 학교 구글 클래스룸**과 연결해 쓰는 방법입니다.
명령어를 칠 필요 없이 웹사이트 화면에서만 진행합니다.

- **비용**: 0원 (구글 클라우드·Vercel 무료 범위)
- **시간**: 약 1시간 + 학교 관리자 승인 대기
- **필요한 것**
  - 학교 **Google Workspace 교사 계정** (예: `teacher@school.sen.hs.kr`) — 개인 Gmail은 안 됩니다
  - GitHub 계정 (무료, 없으면 1단계에서 만듭니다)
  - 학교 Google Workspace **관리자**의 협조 (앱 허용 1회)

> **왜 학교마다 따로 설치하나요?**
> 학생 정보를 다루는 앱이라 구글 로그인을 학교 안에서만 쓰는 **"내부 앱"**으로 만듭니다.
> 내부 앱은 그 학교 계정만 로그인할 수 있어서, 학교마다 각자 설치합니다. 그 대신 구글 심사·비용이 없고 학생 데이터가 학교 구글 계정 밖으로 나가지 않습니다.

---

## 전체 순서

| 단계 | 하는 곳 | 내용 |
|---|---|---|
| 1 | GitHub | 코드를 내 계정으로 복사 (Fork) |
| 2 | 구글 클라우드 | 프로젝트·API·로그인 설정, 클라이언트 ID 발급 |
| 3 | Vercel | 내 사이트로 배포 (클라이언트 ID 입력) |
| 4 | 구글 클라우드 | 배포 주소를 로그인 허용 목록에 추가 |
| 5 | 관리자 콘솔 | 학교 관리자가 앱 허용 |
| 6 | 클래스룸 | 시험용 반에서 확인 |

> 모든 단계는 **학교 계정**으로 로그인한 크롬 창에서 하세요. 크롬 오른쪽 위 프로필로 계정을 확인할 수 있어요.

## 1단계. 코드 복사하기 (GitHub, 5분)

1. https://github.com 에 가입하거나 로그인합니다. (개인 이메일로 가입해도 됩니다)
2. 이 저장소 페이지 오른쪽 위의 **Fork** 버튼 → **Create fork** 를 누릅니다.
3. 내 계정에 같은 이름의 저장소가 생기면 끝입니다. 코드를 고칠 필요는 없습니다.

## 2단계. 구글 클라우드 설정 (학교 계정, 20분)

### 2-1. 프로젝트 만들기
1. https://console.cloud.google.com 에 **학교 계정**으로 접속합니다. (처음이면 약관 동의)
2. 왼쪽 위 **프로젝트 선택** 상자 → **새 프로젝트**
3. 프로젝트 이름: `python-notebook` / **조직**에 학교 도메인이 보이는지 확인 → **만들기**
4. 알림의 **프로젝트 선택**을 눌러 방금 만든 프로젝트로 들어갑니다.

> "프로젝트를 만들 권한이 없습니다" → 학교 관리자에게 프로젝트 생성 권한을 요청하세요.

### 2-2. API 3개 켜기
아래 링크를 하나씩 열고 **사용** 버튼을 누릅니다. (위쪽 프로젝트 이름이 맞는지 확인)
- 클래스룸: https://console.cloud.google.com/apis/library/classroom.googleapis.com
- 드라이브: https://console.cloud.google.com/apis/library/drive.googleapis.com
- 시트: https://console.cloud.google.com/apis/library/sheets.googleapis.com

### 2-3. 로그인 화면 설정
1. https://console.cloud.google.com/auth/overview → **시작하기**
2. 앱 이름 `파이썬 노트북`, 사용자 지원 이메일: 내 학교 이메일 → **다음**
3. **대상: 내부** ← 꼭 "내부"를 고릅니다. (회색으로 막혀 있으면 개인 Gmail로 들어온 것)
4. 연락처 이메일 입력 → 정책 동의 → **만들기**

### 2-4. 권한(범위) 넣기
1. https://console.cloud.google.com/auth/scopes → **범위 추가 또는 삭제**
2. 맨 아래 **수동으로 범위 추가** 칸에 아래 8줄을 통째로 붙여넣고 **표에 추가** → **업데이트** → 맨 아래 **저장**

```
https://www.googleapis.com/auth/classroom.courses.readonly
https://www.googleapis.com/auth/classroom.coursework.students
https://www.googleapis.com/auth/classroom.courseworkmaterials
https://www.googleapis.com/auth/classroom.rosters.readonly
https://www.googleapis.com/auth/classroom.profile.emails
https://www.googleapis.com/auth/classroom.coursework.me
https://www.googleapis.com/auth/drive.file
https://www.googleapis.com/auth/drive.readonly
```

| 권한 | 쓰는 사람 | 용도 |
|---|---|---|
| classroom.courses.readonly | 교사 | 내 반 목록 |
| classroom.coursework.students | 교사 | 과제 만들기, 임시 점수 넣기 |
| classroom.courseworkmaterials | 교사 | 수업 자료 올리기 |
| classroom.rosters.readonly | 교사 | 채점할 때 학생 명단 |
| classroom.profile.emails | 교사 | 채점할 때 학생 이메일(학번) |
| classroom.coursework.me | 학생 | 내 과제 제출 |
| drive.file | 모두 | 이 앱이 만든 파일·시트만 저장 |
| drive.readonly | 모두 | 학생: 선생님 문제 파일 읽기 / 교사: 제출물 읽기 |

### 2-5. 클라이언트 ID 만들기
1. https://console.cloud.google.com/auth/clients → **클라이언트 만들기**
2. 애플리케이션 유형: **웹 애플리케이션**, 이름: `파이썬 노트북 웹`
3. **승인된 JavaScript 원본**은 4단계에서 넣으니 지금은 비워 둡니다. 리디렉션 URI도 비워 둡니다.
4. **만들기** → 나오는 **클라이언트 ID**(`숫자-문자.apps.googleusercontent.com`)를 메모장에 복사해 둡니다.
   - 같이 나오는 "클라이언트 보안 비밀번호"는 쓰지 않습니다. 어디에도 붙여넣지 마세요.

## 3단계. 내 사이트로 배포하기 (Vercel, 10분)

1. https://vercel.com/signup → **Continue with GitHub** 로 가입합니다. (Hobby 무료 요금제 선택)
2. 대시보드에서 **Add New… → Project**
3. **Import Git Repository** 목록에서 1단계에서 Fork한 저장소 옆 **Import**
   - 목록에 없으면 **Adjust GitHub App Permissions** 를 눌러 저장소 접근을 허용합니다.
4. 설정 화면에서
   - **Project Name**: 원하는 이름 (예: `gangnam-python-notebook`). 사이트 주소가 `https://이름.vercel.app` 이 됩니다.
   - **Root Directory**: **Edit** → `notebook` 폴더 선택 ← 꼭 바꿔야 합니다
   - **Environment Variables** 를 펼쳐 2개 추가

     | Key | Value |
     |---|---|
     | `GOOGLE_CLIENT_ID` | 2-5에서 복사한 클라이언트 ID |
     | `SCHOOL_DOMAIN` | 학교 계정의 `@` 뒷부분 (예: `school.sen.hs.kr`) |
5. **Deploy** → 1분쯤 뒤 축하 화면이 나오면 **사이트 주소**를 복사해 둡니다.

> 사이트 파일은 Vercel이 접속한 사람과 가장 가까운 곳(한국에서는 서울)에서 보내 줍니다. 서버 기능 지역도 `notebook/vercel.json`에 서울(`icn1`)로 지정되어 있어 따로 설정할 필요가 없습니다.

> 값을 잘못 넣었을 때: Vercel 프로젝트 → **Settings → Environment Variables** 에서 고친 뒤
> **Deployments** 탭 → 최근 배포의 **⋯ → Redeploy** 를 누르면 다시 반영됩니다.

## 4단계. 배포 주소를 로그인 허용 목록에 넣기 (2분)

1. https://console.cloud.google.com/auth/clients → 2-5에서 만든 클라이언트 클릭
2. **승인된 JavaScript 원본 → URI 추가** → 3단계의 사이트 주소 입력 (예: `https://gangnam-python-notebook.vercel.app`, 끝에 `/` 없이)
3. **저장** (반영까지 몇 분 걸릴 수 있어요)

## 5단계. 학교 관리자에게 앱 허용 요청

학생은 만 18세 미만이라 **관리자가 허용한 앱에만** 로그인할 수 있습니다. 아래 문안에 클라이언트 ID를 넣어 관리자(정보부장, 교육청 담당 등)에게 보내세요.

> **요청: 수업용 앱 "파이썬 노트북" 허용**
>
> 정보 수업과 수행평가를 AI 없이 진행하기 위한 웹 앱입니다. 학교 도메인 **내부 앱**으로 등록했습니다.
>
> 1. **관리 콘솔 → 보안 → 액세스 및 데이터 제어 → API 제어 → 앱 액세스 관리(서드 파티 앱 액세스 구성)**
>    → **앱 추가 → OAuth 앱 이름 또는 클라이언트 ID** → `여기에 클라이언트 ID`
>    → 대상: 학생·교사 조직 단위 → **신뢰함**
> 2. **관리 콘솔 → 앱 → Google Workspace → 클래스룸 → 데이터 액세스**
>    → "사용자가 앱에 Google 클래스룸 데이터 액세스 권한을 부여하도록 허용"이 켜져 있는지 확인
>
> 앱이 하는 일: 클래스룸 과제·자료 게시와 제출, 이 앱이 만든 드라이브 파일 저장, 교사가 공유한 문제 파일 읽기, 교사의 채점 결과 시트 저장.
> 별도 서버나 데이터베이스가 없고, 학생 데이터는 학교 구글 계정(클래스룸·드라이브) 밖으로 나가지 않습니다.

## 6단계. 시험용 반에서 확인하기

학생 계정 하나만 있는 시험용 클래스룸 반을 만들어 두면 편합니다.

1. **교사**: `https://내주소/review.html` → **과제 배포** → 로그인 → 시험용 반, 문제 파일 선택 → **초안으로 저장**
2. 클래스룸에서 초안을 확인하고 **게시**
3. **학생 계정**: 클래스룸 과제의 링크 → 로그인 → 코드 작성·실행 → **제출**
4. 클래스룸에서 "제출함"과 `.ipynb` 첨부 확인
5. **교사**: **채점** 탭 → 평가 선택 → (채점 기준 파일 올리기) → **제출물 불러와서 채점** → **구글 시트로 내보내기**
6. **학교 PC에서도 열어 보기**: 파이썬 실행 엔진을 `cdn.jsdelivr.net`에서 받아옵니다. 학교 방화벽이 막으면 노트북이 "연결 중…"에서 멈춥니다.

| 코드를 순서도로 보기 | 노트북 도구 모음 **☑ 알고리즘 보기** → 코드 옆에 순서도 / 의사코드 |

### 과제·수업 자료를 만들 때 고를 수 있는 설정

| 설정 | 과제 | 수업 자료 | 설명 |
|---|---|---|---|
| 외부 붙여넣기 막기 | ✓ | ✓ | 노트북 안에서 복사한 내용(문제 설명, 자기 코드)은 허용 |
| 알고리즘 보기 끄기 | ✓ | ✓ | 순서도 그리기를 평가할 때. 학생 화면에서 체크박스가 사라지고, 억지로 켜면 작성 기록에 "금지 기능"으로 남음 |
| 작성 과정 기록 | 항상 켜짐 | 선택 (기본 꺼짐) | 붙여넣기·탭 이동·입력 과정 기록 |
| 판서 저장 기능 쓰기 | - | 선택 (기본 꺼짐) | 켜면 판서 팔레트에 **💾 판서 저장** 스위치가 생김 (아래 참고) |

## 수업 기능

### 판서
노트북 도구 모음의 **✏️ 판서**를 누르면 화면 아래에 팔레트가 나옵니다. 화면 공유·전자칠판·태블릿 펜에서 쓸 수 있습니다.

| 도구 | 단축키 | 설명 |
|---|---|---|
| 펜 | `P` | 색 5가지, 굵기 3단계 |
| 형광펜 | `H` | 코드 줄에 반투명하게 칠하기 |
| 레이저 | `L` | 1초쯤 뒤 사라지는 선 (설명하며 가리킬 때) |
| 지우개 | `E` | 문지른 획을 통째로 지움 |
| 되돌리기 | `Ctrl+Z` | 지운 것도 되살림 |
| 닫기 | `Esc` | 그린 내용은 남기고 다시 코드 작성 |

- 판서는 **그린 코드 셀에 붙어 있어서**, 스크롤하거나 위쪽에 출력이 생겨도 그 코드 위에 그대로 있습니다.
- 기본적으로 판서는 **저장되지 않습니다** (새로고침하면 사라짐).
- **판서 저장**: "판서 저장 기능 쓰기"를 켠 수업 자료에서만, 팔레트의 **💾 판서 저장** 스위치를 켜면 그린 내용이 각자 드라이브의 실습 파일에 저장되어 다음 시간에 같은 링크로 들어오면 다시 보입니다. 스위치를 끄면 파일에서 빠지고 화면에만 남습니다. (과제·수행평가에서는 저장되지 않습니다)

### 알고리즘 보기 (순서도·의사코드)
노트북 도구 모음의 **☑ 알고리즘 보기**를 체크하면 모든 코드 셀 옆에 순서도가 나타나고, 코드를 칠 때마다 바로 바뀝니다.

- 시작·끝(둥근 사각형), 입출력(평행사변형), 조건 `if`·`while`(마름모, 예/아니오), `for` 반복(육각형, `i : 1 → 10`), 내가 만든 함수 실행(양옆 이중선)
- 대입은 `total ← total + i`, 비교는 `≥ ≠ =`, `and/or`는 "그리고/또는"으로 표시. 함수는 옆에 따로 순서도가 그려짐
- **의사코드** 탭: "i를 1부터 10까지 바꾸며 반복"처럼 한글 설명으로 표시
- AI가 아니라 **정해진 규칙**으로 바꾸므로 같은 코드는 항상 같은 순서도가 나옵니다. `try`·`class` 같은 문법은 상자 하나로 단순하게 표시됩니다.
- 순서도 그리기를 평가하는 과제에서는 과제를 만들 때 **알고리즘 보기 끄기**를 체크하세요.

**문제 파일 만들기**: 학생 노트북 화면에서 문제를 작성 → **파일 > .ipynb 다운로드**. 코랩에서 만든 `.ipynb`도 그대로 쓸 수 있습니다.

**채점 기준 파일**: 수행평가마다 하나씩 필요합니다. 만드는 방법은 [grading/README.md](../grading/README.md)를 보세요.

## 업데이트 받기

원본 저장소가 업데이트되면, 내 GitHub 저장소 페이지의 **Sync fork → Update branch** 를 누르세요.
Vercel이 자동으로 다시 배포합니다. (설정값은 Vercel 환경 변수에 있으므로 그대로 유지됩니다)

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 화면 위에 "데모 모드"가 보임 | Vercel 환경 변수 `GOOGLE_CLIENT_ID`가 없음 → 3단계 확인 후 Redeploy |
| Vercel 배포 실패: "GOOGLE_CLIENT_ID 형식이 이상해요" | 클라이언트 ID를 잘못 붙여넣음 (`.apps.googleusercontent.com`으로 끝나야 함) |
| 로그인 창에 `origin_mismatch` | 4단계 "승인된 JavaScript 원본"에 사이트 주소가 없음 (끝에 `/` 빼기) |
| 로그인 창에 "액세스 차단됨: 관리자가 차단" | 5단계 관리자 허용이 아직 안 됨 |
| "로그인 창이 열리지 않았어요" | 주소창 오른쪽 팝업 차단 아이콘 → 이 사이트 팝업 허용 |
| 학생: "과제를 찾을 수 없어요" | 과제가 초안이거나, 클래스룸에서 직접 만든 과제. **이 앱의 과제 배포로 만든 과제만** 연동됩니다 |
| 학생: "권한이 없어요" | 다른 반 학생이거나 학교 계정이 아닌 계정으로 로그인 |
| 노트북이 "연결 중…"에서 멈춤 | 학교 방화벽이 `cdn.jsdelivr.net`을 막음 → 정보 담당자에게 허용 요청 |
| 1시간쯤 뒤 "로그인 만료 · 저장 안 됨" | 화면 위 **다시 로그인** 버튼을 누르면 이어서 저장 |

## 개인정보·보안 안내

- 별도 서버·데이터베이스가 없습니다. 학생 코드와 기록은 **학생 본인 드라이브**와 **클래스룸**에, 채점 결과는 **교사 드라이브의 시트**에만 저장됩니다.
- Vercel에는 화면을 그리는 코드(HTML·JS)만 올라가며 학생 데이터는 가지 않습니다.
- 과제에서는 붙여넣기, 다른 탭 이동, 코드 입력 과정이 기록됩니다. 학생 화면에 "작성 과정 기록 중"이 표시되고 과제 안내문에도 적히지만, **평가 계획 안내 때 학생에게 미리 알려 주세요.**
- 작성 기록은 AI 사용을 **완벽히 막지는 못합니다.** 휴대폰을 보며 직접 타이핑하는 경우 등은 기록만으로 판단하기 어려우므로, 기록은 판단을 돕는 참고 자료로 쓰세요.
