# 파이썬 노트북 — AI 없는 코랩형 수업·평가 플랫폼

구글 코랩과 비슷하게 생겼지만 **AI 기능이 전혀 없는** 파이썬 노트북입니다.
구글 클래스룸과 연결해 과제를 내고, 학생 드라이브에 자동 저장하고, 제출·자동 채점까지 할 수 있습니다.

> 코랩에서 "AI 기능 숨기기"를 켜도 오류 도움말 버튼이나 Gemini를 몰래 켜는 문제 때문에 만들었습니다.

## 할 수 있는 것

**학생**
- 브라우저에서 바로 파이썬 실행 (설치 없음): `input()`, matplotlib 그래프(한글 글꼴), pandas 표, numpy 등
- 오류가 나도 "오류 설명" 같은 AI 버튼이 없음
- 클래스룸 링크로 들어와 학교 계정으로 로그인 → 내 드라이브에 자동 저장 → **제출** 버튼

**교사** (`/review.html`)
- **과제 배포**: 여러 반에 한 번에 클래스룸 과제 게시 (마감·배점·붙여넣기 차단)
- **수업 자료**: 제출 없는 실습 자료 배포 — 학생 드라이브에 저장되어 다음 시간에 어느 PC에서든 이어서
- **자동 채점**: 제출물을 모아 채점 기준대로 채점 → 클래스룸 임시 점수 / 구글 시트 / CSV
- **작성 기록 검토**: 외부 붙여넣기, 다른 탭 이동, 자동 입력 프로그램 의심, 기록 조작을 표시하고 입력 과정을 재생

## 특징

- **비용 0원**: 서버·데이터베이스 없음. 정적 사이트(Vercel 무료)와 학교 구글 계정만 사용
- **학생 데이터는 학교 구글 안에만**: 코드·기록은 학생 드라이브와 클래스룸, 성적은 교사 드라이브 시트
- **학교마다 따로 설치**: 구글 "내부 앱"으로 등록해 구글 심사 없이 쓰고, 그 학교 계정만 로그인

## 미리 써 보기 (설치 없이)

`notebook/config.js`에 클라이언트 ID가 없으면 **데모 모드**로 동작합니다(연습용 반·학생 데이터, 브라우저에만 저장).
Python이 설치된 PC라면:

```bash
python notebook/serve.py
```

→ http://localhost:8000/review.html 에서 과제 배포·채점 흐름을 시험할 수 있습니다.
